# WinClientAssess — Changelog

Stable production releases only. Development milestones, release candidates and internal test patches remain in repository history rather than this public release summary.

## v2.2.2 — 2026-10-22

- Improved first-time tool configuration through Tool Readiness, with persisted executable overrides and clear verification feedback.
- Integrated supporting report previews, literal text search, match navigation, path copying, and optional read-only PowerShell search into the Testing Queue.
- Added an integrity reminder when viewing protected evidence and improved target-selection errors, Static progress applicability, MSI review, and manual-test exclusion guidance.
- Retained existing Windows elevation, assessment collection, Guided Runtime, independent reviewer dispositions, manifest integrity, and sanitized Client Appendix behavior.
- Completed a user-reported Windows Full Assessment and Client Appendix field test without issues. Tester selections were synthetic workflow data, not validated security findings.

## v2.2.1 — 2026-10-19

- Added an optional Runtime Observation recommendation in Tester Workspace when an integrity-verified Full Assessment lacks a successful Guided Runtime session.
- Supported browser-local skip/reconsider behavior without changing assessment evidence or previously saved review state.

## v2.2.0 — 2026-10-16

- Introduced the unified Testing Queue and inline linked Guided Review candidates with independent manual completion.
- Streamlined Evidence & Guidance, privacy-safe Client Appendix, and early Administrator elevation for GUI use.
- Released separately packaged tester and full-source distributions.

## v2.1.0 — 2026-10-15

- Improved command provenance, report traceability, and reproducible security evidence collection.
- Strengthened assessment verification and preserved optional tester notes and safe review-state handling.
