# Code of Conduct

Windows Client Assessment contributors are expected to keep project interactions professional, technically focused, and respectful.

Contributors should:

- critique ideas and code without attacking people;
- avoid harassment, discrimination, intimidation, or deliberately disruptive behavior;
- respect confidentiality and never post client assessment data, credentials, proprietary binaries, or private correspondence without authorization;
- disclose conflicts of interest that materially affect technical decisions;
- use security-relevant capabilities only in authorized environments.

Maintainers may edit, remove, or reject contributions or participation that violate these expectations. Serious security or conduct concerns should be raised through an appropriate private channel rather than exposed with sensitive details in a public issue.
